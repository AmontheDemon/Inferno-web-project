# Overview 
This project is a multi-page static website designed for a martial arts gym offering Muay Thai, MMA, and Jiu-Jitsu programs.
It highlights the gym's values, services,pricing, and contract information with clear navigation and a visually compelling design.


# Features
Fully responsive design for mobile,tablet, and desktop
Strutured layout with multiple HTML pages:

Home.html
mma.html (MMA program)
muaythai.html (Muay Thai/KB)
pricing.html (Pricing plans)
contact.html (Contact Info)
kids.html (Kids program)
Bjj.html (Jiu-Jitsu program)
shop.html (Shop page)
about.html (About the gym)
coach.html (Coach page)

Navigation bar 
Embedded videos and images for visual engagement 
Highlighted call-to-action buttons
Section based layout with readable content hierarchy

# Tech Stacks
HTML
CSS
Responsive design (custom queries for different screen sizes
VS Code


# Responsive & Mobile Optimization
Used flexbox for layout alignment and adaptablity 

Custom media queries to adjust font size, image stacking, and section spacing

Images and videos reflow and stack on smaller screens for better UX
